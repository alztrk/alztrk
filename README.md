I’m a developer from Istanbul working across TypeScript, React Native, Python, and Rust. I like turning rough ideas into useful tools, especially where developer experience, local AI, and open source meet.

## Current focus

I’m building **[Tengra](https://github.com/TengraStudio/tengra)**, a cross-platform AI workspace for developers with local model workflows, Git integration, and a Rust-powered sidecar.

My current interests are:

- Local-first AI tools and practical LLM workflows
- Developer workspaces and project operations
- Cross-platform applications with React Native and Tauri
- Open source tools and resources for Turkish developers

## How I build

<table>
  <tr>
    <td width="33%" valign="top">
      <h3>Product</h3>
      <p>I start with a concrete workflow and keep the product surface focused. The goal is a tool people can understand and use, not just a technology demo.</p>
    </td>
    <td width="33%" valign="top">
      <h3>Systems</h3>
      <p>I use local-first architecture, Git-backed workflows, native sidecars, and explicit runtime boundaries when they make the product more reliable.</p>
    </td>
    <td width="33%" valign="top">
      <h3>Open source</h3>
      <p>I document the problem, constraints, setup, and current status so others can evaluate a project before they invest time in it.</p>
    </td>
  </tr>
</table>
